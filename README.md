# Zero Barrier

A job application platform designed specifically for low-tech workers, bridging the digital divide in employment opportunities.

## Features

- 📱 **SMS-Based Job Matching** - Works on any basic phone, no smartphone needed
- 🌐 **No Internet Required** - Complete functionality via text messages
- 🆓 **100% Free for Workers** - No hidden charges or fees
- 📍 **Location-Based Matching** - Find jobs near you
- 💼 **Multiple Job Categories** - Construction, Agriculture, Domestic, Delivery

## How It Works

1. **Send SMS** - Text "JOB" to 55555 from any basic phone
2. **Enter Details** - Reply with your location and preferred work type
3. **Get Matched** - Receive job matches near you within 24 hours
4. **Start Working** - Contact the employer directly and start earning
